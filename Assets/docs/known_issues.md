## 实现与内容缺陷

文档或卡面说好了，游戏里实际不是这样。

| # | 问题 | 位置 | 优先级 |
| ----- | ----- | ----- | ----- |
| B-2 | **玩家挑的牌被忽略**。View 已有选牌界面，但 `ChargeFromZone` 仍取弃牌堆顶或手牌底，不读选择结果。盗贼戏法、以太重组坩埚、应急催化剂受影响 | `BattleEngine.Mutations.cs` | 高 |
| B-17 | **两张形态牌的选择没有入口**。元素增殖炸弹读 `ctx.choice("element")`、炼金防护力场读 `ctx.choice("row")`，但 `CardChoiceCatalog` 里没有它们的条目，于是永远退回默认值（雷属性 / 前排）。和已修掉的旧 B-15 同一类症状，只是这两张不涉及充能。键名对不上不会报错，**只会静默退回脚本里的默认值** | `CardChoiceCatalog.cs` | 中 |
| B-18 | **结算中途的玩家选择没有取消**。出牌**前**的选择（二选一、选元素、从牌堆挑牌）都能取消，取消时什么都还没提交，代价为零；但出牌**后**停下来的选落点窗口（`DecisionKind.ChooseSlot`）只能选、不能退，玩家点开才发现无处可落也只好硬选一格。想做成「取消就回退整张牌」的话，难点不在加按钮：窗口弹出时牌已离手、AP/MP/充能已扣、`CardPlayed` 已发、`OnPlay` 已跑、挂起点**之前**的效果条已经结算（伤害已经打出去了），而 Core 没有任何快照 / 回滚设施（`BattleState` 没有 `Clone()`，`State` 还是 get-only）。将来补「指定目标」这类中断会撞上同一堵墙 | `BattleEngine.SlotChoice.cs` / `BattleEngine.Actions.cs:143-184` | 中 |
| B-13 | **交叉火力网两半句的条件口径不同**。`ResolveCost` 拿不到目标（校验期玩家还没选），所以 AP 减免只能问「本轮有没有队友打过人」，而 +4 伤害才精确到「**这个**目标」。结果是队友打了别人时，这张牌会便宜 1 AP 却不加伤。要修得让费用钩子看得见目标 | `scripts/miku.lua` | 中 |

| B-5 | 加载对账还剩 2 条警告：幸运改命与魔力过载仪式声明了 `behaviourId` 但没有实现——两张都卡在下面「仍未实现的规则」里，等前置做完再补 | 内容包 | 低 |

## 规则书已改、代码未跟上

| 规则书 | 代码现状 |
| ----- | ----- |
| §2.3 角色卡被动 + 角色专属牌 | **两样都没有**。角色数据没有被动字段（唯一像被动的维汀「魔法盾 +1」是死数据，见 B-8）；卡牌类别只有职业 / 武器 / 防具 / 秘宝四种。卡牌 JSON 里有 `owner` 字段，但加载器不读，「只能编进自己卡组」只是靠卡组文件手写保证。<br>2026-11-23 已按语义重新分类：每张职业牌只归属 1 个职业（加载器校验必填 / 非职业牌不许带，`DeckValidator` 校验是不是角色学过的），武器 / 防具只剩角色装备着的那张。**还差的是**从中挑出「角色专属牌」，等策划出候选 |
