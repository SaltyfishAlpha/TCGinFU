## 2. 现状问题

| # | 问题 |
| ----- | ----- |
| Q-1 | **牌效普遍过高**：哈基米N设计的卡组强度离谱，测试 Boss 的血量已经被推到 500+。（现有内容包里的克洛诺斯-IV 是 140 HP，说明是另一套测试数据。）需要先定一个**数值基准**，再回头校准现有卡。 |

## 3. 卡组结构

### 3.1 卡组组成（✅ 已确认，与 v0.5 一致）

主卡组 = **职业牌 + 武器牌 + 防具牌 + 秘宝牌 + 升变牌**；升变牌另带一副额外卡组。

- **职业牌**内部再细分，比如「职业核心体系牌」。
- **武器牌 / 防具牌是一个类别，不是特指两张牌**。它们承担基础攻防（类似「打击」「防御」），
  而且会随着拿到更强的装备而变化（与 v0.5 §7.2 一致）。
- **秘宝牌**：职业只有 5 个技能，后期成长主要是加数值和加牌效。秘宝在游戏过程中能拿到很多张，
  看能否与职业搭配出提升，主要作用是**给卡组带来新鲜感**。

### 3.2 配比限制（❗ 与 v0.5 冲突）

- 怪人：「倒是没有强制各个构成的配比。」
- 基础攻防牌可能被玩家**优化出卡组**，这是可以预见的。但「是否允许优化掉」还没想过。
- **✅ 已定（11-22 追加）：完全取消类别配比**，只保留 30 张总数与同名上限；允许把基础攻防牌全部优化掉，
  靠强度设计调节（基础牌稳定但不亮眼）。已写入规则书 §3.2。

> 规则书 §3.2 写了硬区间（职业牌 12–16 / 武器牌 3–8 / 防具牌 3–8 / 秘宝牌 0–6），
> `DeckValidator.CategoryRules` 也按这个区间做了校验。需要确认是**取消配比**，还是**保留下限、放开上限**之类的折中。

### 3.3 角色特有体系（🆕 v0.5 没有这一层）

- 例子：维汀的骰子体系小巧思（「灵智回流」，可能还包括「星穹坍缩」）；
  盐焗小鱼的角色也有一个「超大吟唱、多回合」的技能，但没做成卡牌。
- 定性为**玩家（角色）特有**，与职业特点区分开。
- **不一定做成卡牌**，也可以是场外机制。
- **✅ 已定（11-22 追加）：角色卡被动 + 角色专属牌两种载体并存。**
  - 角色卡被动：印在角色卡上，常驻生效，不占卡组，适合贯穿全局的规则改写（如维汀的骰子体系）。
  - 角色专属牌：只有该角色能编入，计入 30 张，适合需要时机选择的主动技能（如多回合大吟唱）。
  - 已写入规则书 §2.3、§3.2、§7.1。
- ❓ 仍待定：每名角色几条被动、专属牌几种及同名上限、是否随剧情成长。

> 现状：「灵智回流·常驻」在 `weiting.json` 里是一张 `混沌法师` 职业牌，数据上没有「角色专属」这个归属。

### 3.4 升变与额外卡组（✅ 与 v0.5 一致）

- 主卡组 30 张，其中含升变牌；**每张升变牌对应一副 10 张的形态卡组**。
- 目前「额外卡组」专指升变卡组。
- 形态卡组是一个**小循环**：每轮抽 5 张，2 轮抽完就退出升变，回到主卡组。
- **可以带两张升变牌（两副形态卡组）**，没有限制，因为升变本身要达成条件。
- 升变条件**目前跟职业牌相关**。

### 3.5 卡组张数

- 盐焗小鱼担心 **30 张对新手卡组来说太多** → **❓ 待定**（怪人没有表态）。

## 4. 卡牌获取来源（💡 提议，怪人评价「感觉可以啊」「天才！」）

| 卡牌类型 | 提议来源 |
| ----- | ----- |
| 职业牌 | 职业任务；另外是升级、学技能（§5） |
| **升变牌** | **个人主线**：每完成一个重大节点，获得一张新的升变牌 |
| 职业版升变牌 | 职业任务大结局 |
| 杂项动作牌 | 刷小怪掉落 |
| 秘宝牌 | 大 Boss、特殊事件、战役完成奖励、开宝箱 |
| 武器 / 防具牌 | 拿到更强装备时随之换代（§3.1） |

**这条解决了一个原有痛点**：升变牌如果只绑职业，总共只有寥寥几张。
改成跟个人主线挂钩后，升变牌的数量能撑起来，**还能推动玩家去跑主线**。

> ❗ 与 v0.5 冲突：§3.1 写的是「习得某职业即可编入该职业的升变牌」，
> `DeckValidator` 也校验了「升变牌要求角色拥有对应职业」（`transform.ClassId`）。
> 主线升变牌没有职业归属，需要新增「角色专属 / 主线」这种升变来源。

## 5. 成长：技能 → 卡牌

| # | 内容 | 状态 |
| ----- | ----- | ----- |
| G-1 | FU 每个职业 5 个技能，**每个技能衍生 3–5 种牌，每种编入 1–3 张**。新手 5 级有 5 个技能，牌的种类就足够了 | ✅（数字与 v0.5 略有出入，见下） |
| G-2 | 5 级是双职业，10 级可以把两个职业的技能点满 | ✅（沿用 FU） |
| G-3 | **敲牌（升级卡牌）**：技能等级提升时**升级已有的牌**，主要是加数值，升到一定程度还会**加新效果** | ✅ |
| G-4 | **法术库**：法师类点一级法术技能，就从法术库（十几个法术）里**自选**一个学习。所以实际技能量是「4 个技能 + 法术库」，例如奶妈是 4 + 13。对应到卡牌：**在限定范围的卡池里自选一张加入卡池**（不是随机） | ✅ |
| G-5 | 职业 10 级获得英雄技能 → 对应卡牌或被动 | ✅（与 v0.5 §3.3 一致） |

> 与 v0.5 的出入：
> - §3.3 写的是「每个技能 3 种基础牌，每种最多 3 张」，讨论说的是「3–5 种，每种 1–3 张」。
> - §3.3 把技能升级写成「SL2+ **额外解锁**新的衍生牌」，讨论说的是「**升级已有的牌**（敲牌），升多了再加新效果」。
>   两种可以并存，需要确认。
> - 规则书里没有「法术库自选」这个机制。

## 6. MVP 推进建议（💡 盐焗小鱼提议）

先做 1–2 个角色，每个角色包含：

1. 角色牌
2. 角色体系牌（§3.3）
3. 1–2 张升变牌及其形态卡组
4. **普通攻防牌**：攻击 / 重击 / 平砍 / 连击 / 顺劈；防御 / 超级防御 …
5. 现有职业的职业牌

做稳以后**一个一个加职业**。怪人的回应：「先把你们已经有的职业搞好吧。」

## 8. 与现有实现的差距

| 讨论内容 | 现有实现 | 差距 |
| ----- | ----- | ----- |
| 取消配比 ✅ | `DeckValidator.CategoryRules` 仍硬校验 12–16 / 3–8 / 3–8 / 0–6 | **删掉类别区间校验**，保留 30 张与同名上限；相关测试要同步改 |
| 主线升变牌 | 升变牌只有 `ClassId` 归属，校验要求角色拥有该职业 | 缺「角色专属」归属（可与下一行共用） |
| 角色卡被动 ✅ | 角色数据（`heroes.json`）没有被动字段；引擎的常驻钩子只枚举持续区、升变牌、状态 | 角色加 `passiveBehaviourId` 一类字段，并把角色被动纳入常驻行为枚举（`ActiveBehaviours`） |
| 角色专属牌 ✅ | `CardCategory` 没有这一类；「灵智回流·常驻」挂在 `混沌法师` 下 | 新增类别或 `CharacterId` 归属，`DeckValidator` 校验「只有该角色能编入」；现有维汀/米阔阔的牌要重新归类（哪些是角色的、哪些是职业的） |
| 普通攻防牌 | 武器、防具牌都是角色专属的特色牌（如「游击速射」「奥术结界」） | 缺一套通用的基础攻防牌 |
| 卡牌获取 / 成长 / 敲牌 / 法术库 | **完全没有**：只有战斗，没有战役、掉落、卡池管理 | 整个局外层未开始 |
| 数值基准 | 内容包 Boss 140 HP；没有数值设计文档 | 需要先定基准 |
