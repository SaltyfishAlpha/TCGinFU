## 1. 不只是文档问题：实现与内容的真实缺陷（建议转给开发）

## 2. README.md

- **过时** 进度表：写着「140 个测试」「表现层尚未开始」「ScriptableObject 数据层待实跑」。实际测试约 **227** 个（194 个 `[Test]` + 33 个 `[TestCase]`）；表现层已经是可用的 3D 桌面；内容走 JSON 包 + Lua，`TCGinFU.Data`（ScriptableObject）**已经没有任何程序集引用，是死代码**。
- **过时** 入口：只写了 `生成战斗场景`（`Battle.unity`，用 C# 写死的样例内容）。实际还有 `生成命刻之战场景` → `ClockworkCollapse.unity`，读 JSON 内容包，**而且它是构建设置里唯一的场景**。
- **错误** 操作说明：「左键点手牌 = 出牌」实际只弹提示。顶栏漏了随阶段变化的主按钮（结束行动 / 不升变 / 放弃响应 / 自动弃牌 / 取消充能）和「退出」。漏了长按看详情、拖角色卡走位、拖升变牌升变、右键角色卡看详情、Esc 退出。
- **缺失** 代码结构：没有 `Scripting/`（Lua），没有 `StreamingAssets/Content` 内容包。
- **过时** 下一步 / 已知缺口：仍以 ScriptableObject 资产为第 2 步；裁定待办数量不对。
