## 1. 产品方向（已有共识，未成文）

- **不卖卡包**，所以不需要「注水卡」。但仍然需要「通用件」：过牌、定向检索、让卡组转得动的润滑牌。
- 更接近 **LCG / 成长型卡牌游戏**：卡池随角色成长和冒险进度扩充，而不是靠抽卡包。
- **基础卡要简单**，不能一上来全是一长段文本的复杂体系牌。

## 2. 提议

### 2.1 卡牌获取来源（有正面回应，未拍板）

| 卡牌类型 | 来源 |
| ----- | ----- |
| 职业牌 | 职业任务；升级、学技能 |
| **升变牌** | **个人主线**：每完成一个重大节点，获得一张新的升变牌 |
| 职业版升变牌 | 职业任务大结局 |
| 杂项动作牌 | 小怪掉落 |
| 秘宝牌 | 大 Boss、特殊事件、战役奖励、宝箱 |
| 武器 / 防具牌 | 获得更强装备时换代 |

这条解决了「升变牌只绑职业，总共只有几张」的问题，还能推动玩家去跑主线。
**与规则书冲突**：§3.1 要求升变牌属于某个职业。主线升变牌需要新的归属，可以和 §2.3 的「角色专属」共用。

### 2.2 技能成长（方向已认可，规则书写法不同）

- 每个技能衍生 **3–5 种**牌，每种编入 **1–3 张**（规则书 §3.3 写的是 3 种、最多 3 张）。
- **敲牌**：技能升级时**升级已有的牌**，主要加数值，升到一定程度再加新效果（规则书写的是 SL2+ 解锁新的牌）。
- **法术库**：法师类每点一级法术技能，就从十几个法术里**自选**一个（例如奶妈是 4 个技能 + 13 个法术）。规则书里没有这个机制。

### 2.3 MVP 推进顺序（盐焗小鱼提议）

先做 1–2 个角色，每个角色包含：角色牌、角色体系（被动 + 专属牌）、1–2 张升变牌及形态卡组、
普通攻防牌（攻击 / 重击 / 平砍 / 连击 / 顺劈；防御 / 超级防御…）、现有职业的职业牌。
做稳之后一个一个加职业。

## 4. 职业方向（开发中，随时会变）

每张职业牌只归属 1 个职业（规则书 §7.1）。目前定下方向的职业：

| 职业 | 核心机制 |
| ----- | ----- |
| T（护卫类） | 挨打叠层，层数换护盾或反伤；叠满后在升变期间无敌 |
| N（贤者） | 选定一名角色，之后每打一张牌就给他小幅治疗；他满血时改为加护盾 |
| 元素使 | 轮换着使用不同元素的法术会获得加成 |
| 博学家 | 一半是响应牌，主要攒资源、从弃牌堆摸牌，或者闪避 |
| 熵术士（原「混沌法师」） | 沿用原作的骰子改判 |
| 造物使 | 单独开一个装置区，用充能牌玩三消 |
| 浪客 | 可以把牌当陷阱卡用 |
| 神射手 | 站位不同效果不同；同一回合内连段有加成 |

现有两名角色的职业：米阔阔 = 浪客 + 神射手，维汀 = 熵术士 + 造物使。
现有卡牌的机制和这些方向**大多对不上**（例如浪客牌里没有陷阱，造物使牌里没有装置区），重做职业时要按这张表重新设计。

## 5. 规模

计划 15 个职业，外加角色专属体系、武器 / 防具换代、秘宝、升变卡组，以及对应的卡图。
**严格来说目前还没有一个职业做完整。**
