# 最终物语 · 打牌战斗规则书 v0.5

> **版本定位**：基于《最终物语》（Fabula Ultima，简称 FU）TRPG 框架的**局内协同 TCG 对战系统**。
> **核心体验**：跑团探索采用 FU 原规则；一旦进入战斗冲突，切换为本卡牌系统进行小队协同打牌；战斗结束后，角色的 HP、MP 与状态直接带回跑团。

## 1. 总定义与资源跨局承接

**一场战斗** $=$ **一局牌。** 卡组在战斗外由玩家自由构筑完成（TCG 模式），战斗过程中不增删主卡组卡牌（升变形态切换除外）。

| 游戏阶段 | 适用规则与结算逻辑 |
| ----- | ----- |
| **探索、交涉、休整** | 采用《最终物语》原规则（属性检定、命刻、扎营与道具恢复） |
| **进入战斗冲突** | 切换为**本卡牌规则**，按角色当前剩余 HP 与 MP 入场 |
| **冲突结束** | 剩余 HP、剩余 MP 与持续状态直接带回跑团，**战斗开始与结束均不自动回满 HP/MP** |

## 2. 角色面板、等级成长与卡牌转化

### 2.1 角色基础属性（还原 FU $50$ 级上限）

| 项目 | 规则与计算公式 |
| ----- | ----- |
| **初始等级与上限** | 初始 $5$ **级**，等级上限 $50$ **级**（与 FU 原作完全一致） |
| **多职业构筑** | 初始选择 $2\text{--}3$ 个职业共享等级（例：浪客 $3$ 级 $+$ 神射手 $2$ 级）；单职业上限 $10$ 级，满 $10$ 级即精通该职业并获得 $1$ 张**英雄技能牌** |
| **四色属性骰** | 力量（**红**）／洞察（**蓝**）／敏捷（**绿**）／意志（**紫**），骰面等级为 $\text{d6}$、$\text{d8}$、$\text{d10}$、$\text{d12}$（计算面板数值时取 $6, 8, 10, 12$） |
| **属性骰等级成长** | 角色总等级达到 $20$ **级**与 $40$ **级**时，各获得 $1$ 次将任意一项属性骰提升 $1$ 个等级的机会（$\text{d6} \to \text{d8} \to \text{d10} \to \text{d12}$，上限 $\text{d12}$） |
| **最大 HP** | $\text{角色总等级} + (\text{力量骰等级} \times 5) + \text{职业与秘宝加值}$ |
| **最大 MP** | $\text{角色总等级} + (\text{意志骰等级} \times 5) + \text{职业与秘宝加值}$（跨战斗保留，不随战斗自动回满） |
| **危机值** | $\lfloor \text{最大 HP} \div 2 \rfloor$（HP 降至危机值或以下时进入危机状态，可触发危机词条） |
| **自动物理护盾** | $\text{敏捷骰等级} \div 2$（每轮开始时自动获得，用于抵消物理伤害，每轮结束时清零重置，不跨轮叠加） |
| **自动魔法护盾** | $\text{洞察骰等级} \div 2$（每轮开始时自动获得，用于抵消魔法伤害，每轮结束时清零重置，不跨轮叠加） |

### 2.2 四色属性与卡牌颜色对应

所有职业牌、武器牌与技能牌均带有颜色标识，对应角色的四项基础属性：

| 卡牌颜色 | 对应属性 | 常见关联职业与武器类型 |
| ----- | ----- | ----- |
| **红色（Red）** | **力量（Might）** | 武器大师、狂战士、护卫者；重型近战武器、格斗武器 |
| **蓝色（Blue）** | **洞察（Insight）** | 博学者、神射手、元素使；奥术武器、火器、战术技能 |
| **绿色（Green）** | **敏捷（Dexterity）** | 浪客、舞者、神射手；弓箭、匕首、投掷武器、手里剑 |
| **紫色（Purple）** | **意志（Willpower）** | 灵媒、吟游诗人、暗黑骑士；法杖、魔导书、精神与诅咒技能 |

*注：还原原作双属性检定的卡牌会拥有**双色标识**（如绿 $+$ 蓝、红 $+$ 紫）。*

### 2.3 角色特有体系（角色卡被动 $+$ 角色专属牌）

职业决定「会什么」，角色特有体系决定「这个人是谁」。它与职业无关，换职业、混搭职业都不改变它。分为两种载体：

| 载体 | 规则 | 适合的机制 |
| ----- | ----- | ----- |
| **角色卡被动（光环）** | 印在角色卡上，战斗全程常驻生效，**不占主卡组张数**，无需抽到 | 贯穿整局的规则改写，例如维汀的骰子体系 |
| **角色专属牌** | 只有该角色能编入的牌，**计入主卡组 $30$ 张** | 需要时机选择的主动技能，例如多回合大吟唱 |

*待定：每名角色的被动条数（初步设想为 $1$ 条）、角色专属牌的种类数与同名上限、两者是否随剧情成长。*

## 3. 卡组构筑与长线成长规则

### 3.1 双层卡组架构与升变自由构筑

* **主卡组（固定 $30$ 张）**：战斗前由玩家自主构筑，可包含职业牌（含升变牌）、武器牌、防具牌、秘宝牌与角色专属牌，**各类别不设配比**（见 §3.2）。随着角色等级从 $5$ 级升至 $50$ 级，**增长的是玩家的可选卡池（Card Pool），主卡组张数恒定为 $30$ 张**。
* **形态额外卡组（每张升变牌 $10$ 张）**：置于场外形态槽中，不计入主卡组 $30$ 张上限。**形态卡组由升变牌自身定义**：每张升变牌固定带一组 $10$ 张形态牌，玩家不自行挑选里面放哪些牌。唯一的例外是主动型英雄技能牌的替换（§3.3）。
  同一张形态牌可以出现在多张升变牌的形态卡组里。
* **升变牌构筑自由度**：只要角色习得了某职业，即可选择是否将该职业的「升变牌」编入主卡组（**同名升变牌限编入 $1$ 张，不限制不同职业升变牌的总携带张数**）。主卡组中每编入 $1$ 张升变牌，场外即配置**这张升变牌**的那组形态额外卡组。携带多张升变牌带来的爆发多样性与抽牌构筑权衡，完全交由玩家自行决策。

### 3.2 主卡组 $30$ 张构成与同名限制

**主卡组只约束总张数（恒定 $30$ 张）与同名上限，不设类别配比。** 任何类别都可以是 $0$ 张，包括武器牌与防具牌——
把基础攻防牌整体优化出卡组是被允许的构筑选择，由卡牌强度设计自然调节，而不是用规则强制。

| 卡牌类别 | 同名牌上限 | 卡池解锁来源 |
| ----- | ----- | ----- |
| **职业牌（含升变牌）** | 普通职业牌 $3$ 张 / **同名升变牌限 $1$ 张** | 已学职业技能（每个技能解锁 $3\text{--}6$ 种牌） |
| **武器牌** ⏸ | $3$ 张 | 当前装备槽中的武器（随等级阶梯换代）。规则暂时静默，见 §7.1 |
| **防具牌** ⏸ | $3$ 张 | 当前装备槽中的身体防具与盾牌（随等级阶梯换代）。规则暂时静默，见 §7.1 |
| **秘宝牌** | $3$ 张 | 跑团中获得的秘宝（遗物） |
| **角色专属牌** | 待定 | 角色本身（见 §2.3） |
| **主卡组合计** | **恒定 $30$ 张** | 随等级提升扩充可选卡池与单卡等阶 |

*设计含义：基础攻防牌应当「稳定但不亮眼」，作为卡池浅时的兜底；卡池变深后被替换掉，正是成长的体现。*

### 3.3 职业技能卡牌转化与 $10$ 级精通（英雄技能牌）

1. **基础解锁（SL1）**：每学习 $1$ 个职业技能（含原作中的主动与被动技能），即解锁该技能对应的 $3$ **种基础职业牌**（起手运转牌、核心执行牌、终结/响应牌）。每种最多可编入 $3$ 张，即 $1$ 个技能提供 $9$ 张可选牌。
2. **高技能等级（SL2+）**：当在同一技能投入更高等级时，额外解锁该技能专属的 $1\text{--}3$ **种高阶衍生牌**，拥有更强的数值与机制联动。
3. **被动技能重构**：原作中的被动技能转化为「提供对应词条增益的行动牌」或「置入场上持续区的**持续牌**」。
4. **$10$ 级职业精通与英雄技能牌**：当单个职业达到 $10$ 级上限（精通）时，获得 $1$ 张专属**英雄技能牌**：
   * **主动型英雄技能牌**：直接编入该职业的「形态额外卡组」中（替换其中 $1$ 张基础形态牌，或在开启该职业升变时直接额外加入手牌），使满级职业的升变拥有终极必杀技。替换哪一张由玩家在构筑时选定，这是玩家能改动形态卡组的唯一方式；
   * **被动型英雄技能牌**：直接赋予角色常驻面板强化或特殊规则加成。

## 4. 战场区域、前后排站位与援护

### 4.1 角色个人面板区域

每位玩家面前设有以下区域：

1. **主卡组区**：战斗全程不被顶替。升变期间不从这里抽牌，但牌一张不动。
2. **升变卡组区**：发动升变后，该升变牌自带的 $10$ 张形态牌洗入此区，升变期间从这里抽牌。抽空即抽空，不以弃牌堆续牌。
3. **弃牌堆**：主卡组的弃牌堆。
4. **形态弃牌堆**：升变期间打出或弃置的形态牌堆在此处，与主弃牌堆是**两摞**（界面上合并展示）。
5. **持续区（上限 $1$ 张）**：打出的「持续牌」置于此区域持续生效，不进入弃牌堆；若打出新的持续牌，旧持续牌被顶替并置入弃牌堆。
6. **充能区（上限为 $\max(\text{玩家人数} - 1, 2)$）**：存放作为充能指示物的卡牌。若充能已满时继续充能，将最早置入的充能牌顶入**该卡牌原持有者的弃牌堆**。
7. **除外区**：移出本局的牌，不会再以任何方式回到卡组、手牌或弃牌堆。两条来源：
   - 卡面写有「**消耗**」或「使用后置入除外区」的**一次性牌**，打出结算完直接置入；
   - 升变牌及它那 $10$ 张形态牌，在弹出升变时**整套**置入（见 §6.2 ⑤）。

> 升变牌本身若**没有被打出**，而是因其他效果或手牌上限被弃置，它进的是**主弃牌堆**——它这时还只是一张普通的手牌。

### 4.2 前后排站位与走位规则

战场分为**前排**与**后排**，每排人数上限为 $4$ 人，不强制要求前排必须有人。玩家的近战、远程或魔法攻击**不受所处排位限制**。

| 机制项 | 判定规则 |
| ----- | ----- |
| **常规仇恨指向** | 大部分敌人的单体攻击意图默认优先指向**前排角色**；若前排无人，则优先指向后排**上一轮造成伤害最高**的角色。 |
| **排位机制应对** | 部分敌人意图会指定「前排全体 AOE」、「后排全体 AOE」或「指定某排单体死刑重击」。 |
| **排位移动（走位）** | 在玩家阶段，角色可消耗 $1\text{ AP}$ 移动 $1$ 次，以此规避特定排位伤害、主动上前排承伤或挪到队友身边以便援护。落点为**任意排的任意位置**：换到对排、或在本排内改变左右相对位置，都算这 $1$ 次移动。目标位置已有队友时将其**挤开**（沿途的人朝空位方向平移一格），因此满员的排内部仍可调整站位。 |

### 4.3 相邻定义与援护机制

* **相邻范围判定**：
  1. 与自己处于**同一排左右紧邻**的角色视为相邻；
  2. 所有后排角色均视为与**正前方的前排角色**彼此相邻。
* **援护动作**：在敌人阶段，当相邻队友成为攻击目标时，任何玩家均可从自己手中打出**时机牌**（例如防具类的时机牌）替该队友承受伤害或提供护盾。护卫者等防御向职业拥有大量强力专属援护牌。

## 5. 手牌运转与充能系统（FAB 式资源转化）

### 5.1 抽牌规则

* **第 $1$ 轮**：战斗开始时，每位玩家从主卡组抽 $5$ **张**起始手牌。
* **第 $2$ 轮及后续常态轮次**：每轮的补牌阶段，每位玩家固定从主卡组抽 $3$ **张**牌（轮末手牌上限为 $7$ 张，超出部分弃置）。

### 5.2 充能系统（手牌转 MP / AP）

由于跑团中 MP 不会每战自动回满，玩家可通过「充能」将手牌转化为战斗资源：

1. **贴充能动作**：在玩家阶段，每名角色每轮**最多可执行 $1$ 次**「贴充能」动作（消耗 $0\text{ AP}$）——将自己手中的 $1$ 张任意卡牌正面朝下（或横置）贴入**自己或任意队友的充能区**，作为 $1$ 个「充能指示物」。
2. **充能指示物的消耗**：角色在出牌或行动时，可随时消耗自己充能区中的 $1$ 个充能指示物，从以下效果中三选一：
   * **转化为 MP**：立即回复 $5\text{ MP}$（与普通回复相同，不超过 MP 上限）；
   * **转化为行动力**：本回合立即获得 $+1\text{ AP}$；
   * **触发卡牌词条**：支付特定职业牌上的「消耗 $X$ 个充能」强力追加效果。

   一个充能只能选一种用途：用来转化为 MP 的充能，**不算**支付了卡面的「消耗 $X$ 个充能」。
3. **充能结算归宿**：充能指示物被消耗后，立即进入**该卡牌原持有者的弃牌堆**（若一直未消耗，则持续留在充能区中，不参与洗切）。

## 6. 升变机制（短期爆发形态与动态数值）

### 6.1 升变牌的触发方式与第 $3$ 轮保底

升变牌编入 $30$ 张主卡组中（同名限 $1$ 张），分为以下两类：

* **条件型升变牌**：卡面写有前置条件（如：造成过暴击、全队累计消耗过 $3$ 个充能等）。在条件未达成或第 $3$ 轮前抽到时，玩家可免费发动其手里效果：**展示该牌并洗回主卡组，随后抽 $1$ 张牌**。
* **即发型升变牌**：触发条件即为「抽到该牌或该牌在手牌中」，允许特定职业在**第 $1$ 或第 $2$ 轮直接开启升变**。
* **第 $3$ 轮保底跳出**：若到了**第 $3$ 轮开始时**，主卡组中的升变牌仍未被摸到且满足前置条件，玩家可选择让 $1$ 张升变牌直接从主卡组自动跳出并发动升变。

### 6.2 升变执行流程（持续 $2$ 轮的形态卡组替换）

升变仅能在每轮开始时（意图揭示后、常规抽牌前）发动，持续整整 $2$ **轮**：

```
【进入升变（升变第 1 轮）】
① 暂存原手牌：将当前手牌暂存至场外（主卡组、持续区与充能区的牌都原样留在场上！）
② 放出形态组：将对应的 10 张「形态额外卡组」洗切后放入**升变卡组区**，获得该形态的被动加成
   （若该职业已达 10 级精通且带有主动型英雄技能牌，按卡面说明将其洗入或直接置入手牌）
   这期间从升变卡组抽牌，主卡组不动——两个卡组区并存，不是互相顶替
③ 形态首轮抽牌：从升变卡组抽 5 张牌，代替本轮常规抽牌

【升变维持（升变第 2 轮）】
④ 形态次轮抽牌：在下一轮补牌阶段，将升变卡组剩余的 5 张牌全部抽上手，打完第 2 轮爆发

【退出升变（第 3 轮开始时）】
⑤ 移除形态牌：将本张升变牌及全部形态牌（含形态弃牌堆与手上剩余的）整套置入**除外区**，移出本局游戏
⑥ 恢复手牌：拿回此前暂存的原手牌，并从主卡组正常执行本轮的常规抽牌（抽 3 张）
```

### 6.3 形态卡组的动态基准公式（武器/防具 $+$ 角色等级）

为确保形态额外卡组从 $5$ 级到 $50$ 级始终保持高爆发爽感，形态牌上的伤害与护盾不采用固定死数值，而是基于**「当前装备数值 $+$ 角色等级加值」**动态计算：

* **角色等级加值（$L_{\text{bonus}}$）**：
  $$L_{\text{bonus}} = \lfloor \text{角色总等级} \div 5 \rfloor$$
  *（即：$5\text{--}9$ 级为 $+1$，$20\text{--}24$ 级为 $+4$，$50$ 级满级时为 $+10$）*
* **形态攻击基准值（$B_{\text{atk}}$）**：
  $$B_{\text{atk}} = \text{当前武器牌基础伤害} + L_{\text{bonus}}$$
* **形态防御基准值（$B_{\text{def}}$）**：
  $$B_{\text{def}} = \text{当前防具牌基础护盾} + L_{\text{bonus}}$$

*示例：形态卡组中的强攻牌写为「造成 $B_{\text{atk}} + 4$ 点伤害」，在 $5$ 级持短弓（武器伤 $7$，$L_{\text{bonus}} = 1$）时造成 $7 + 1 + 4 = 12$ 点伤害；在 $50$ 级持三阶神器弓（武器伤 $13$，$L_{\text{bonus}} = 10$）时则自动成长为 $13 + 10 + 4 = 27$ 点伤害！*

## 7. 牌的四大来源、等级阶梯、暴击与属性克制

### 7.1 卡牌的两个维度：类别与打法

每张玩家卡牌同时有一个**类别**和一个**打法**，两者互不相干：

* **类别**决定这张牌从哪来、谁能编入（见下方类别表）；
* **打法**决定它什么时候打、打出后去哪。

例如游击速射是「武器牌 · 技能」，看破闪避是「防具牌 · 时机」。

**打法（只有三种）**

| 打法 | 打出时机与去向 |
| ----- | ----- |
| **技能** | 玩家阶段主动打出，耗 AP / MP，当场结算后进入弃牌堆 |
| **时机** | 留在手中，在敌人阶段或队友行动时作为响应打出 |
| **持续** | 置入持续区，常驻生效（§4.1） |

**不属于打法的标记**：下面三样是另外的标记，不是第四、第五种打法。

| 标记 | 含义 |
| ----- | ----- |
| **升变牌** | 主卡组里触发升变的牌（§6）。它本身不按打法结算，而是走升变宣告 |
| **形态牌** | 只能放进形态额外卡组，不能编入主卡组；只在升变期间抽到（§6.2）。哪张升变牌带哪些形态牌，由升变牌定义（§3.1）。形态牌**仍然有自己的打法**，例如烟幕替身是「形态牌 · 时机」 |
| **敌人意图** | 敌人宣告的行动（§8 ④）。不是玩家卡牌，不能编入卡组，不进手牌；结算沿用卡牌效果体系 |

**类别**

| 卡牌类别 | 结算与核心机制 |
| ----- | ----- |
| **职业牌** | 职业技能转化而来的牌（§3.3），可以是任意打法。**每张职业牌只归属 $1$ 个职业**，不分主职业、副职业：角色学了哪个职业，就能编入该职业的牌。**英雄技能牌**（职业 10 级精通所得）属于职业牌，也可以是任意打法。武器牌、防具牌、秘宝牌、角色专属牌**不带职业**。 |
| **武器牌** ⏸ | 基础进攻手段（只耗 AP 不耗 MP）。一阶基础伤害公式为：$\lfloor \text{武器原固定伤害} \div 2 \rfloor + 3$。单手武器偏向低费高频率，双手武器偏向高费高单发伤害。 |
| **防具牌** ⏸ | 基础防御与援护手段。提供物理/魔法护盾或减伤反应，其中打法为「时机」的防具牌可在敌人阶段对自身或相邻队友打出；打法为「技能」的防具牌只能在玩家阶段打。 |
| **秘宝牌** | 跑团遗物衍生卡。提供 $1$ 个场外被动或 $2\text{--}3$ 张不受职业限制的特殊功能牌。 |
| **角色专属牌** | 不属于任何职业，只有对应角色能编入。体现角色个人的主动技能（如多回合大吟唱），见 §2.3。 |

*注：加上角色专属牌后为五类。角色卡被动不是牌，不在此表中。*

> ⏸ **武器牌 / 防具牌的定位仍在讨论，相关规则暂时静默**：§3.2 表中的武器、防具两行，本表的武器、防具两行，以及 §7.2 整节，目前都不作为构筑或数值约束。
> 唯一仍然生效的是「角色装备着的那张武器 / 防具牌提供 $B_{\text{atk}}$ / $B_{\text{def}}$」（§6.3，裁定 R-19），因为形态牌的数值依赖它。
> 讨论见 [design_backlog.md](design_backlog.md) O-11。

**响应窗口能打出什么**：只有打法为**时机**的牌，与类别无关。

### 7.2 武器牌与防具牌的等级阶梯换代（适配 $50$ 级成长）

> ⏸ 本节暂时静默，见 §7.1 末尾。

参照《最终物语》原作的等级跃迁节点，武器牌与防具牌随角色等级与高阶装备更换分为三个阶梯：

| 角色等级阶段 | 装备牌阶梯 | 武器牌伤害补正 | 防具牌护盾补正 | 对应 FU 原作阶段 |
| ----- | ----- | ----- | ----- | ----- |
| **$\text{L5}\text{--}\text{L19}$** | **一阶（基础武具）** | 基础值（$3\text{--}10$ 点） | 基础值（$6\text{--}10$ 点） | 初始建卡与早期冒险 |
| **$\text{L20}\text{--}\text{L39}$** | **二阶（进阶/稀有）** | 一阶基础值 $+ 3$ | 一阶基础值 $+ 3$ | 原作 $\text{L20}$ 进阶成长节点 |
| **$\text{L40}\text{--}\text{L50}$** | **三阶（传奇/神器）** | 一阶基础值 $+ 6$（并附带专属词条） | 一阶基础值 $+ 6$（并附带专属词条） | 原作 $\text{L40}$ 终局传奇节点 |

### 7.3 四色暴击判定与「超暴击」

只有卡面带有 **【暴击】** 标识的攻击牌或技能牌在打出时才需要投掷暴击骰。投掷哪颗骰子取决于**该卡牌的颜色**（红投力量骰、蓝投洞察骰、绿投敏捷骰、紫投意志骰）：

* **单色【暴击】牌**：投掷对应的 $1$ 颗属性骰（$\text{d6}\text{--}\text{d12}$），若骰出点数 $\ge \text{敌方暴击抵抗}$，则触发**暴击**，本次伤害 $\times 1.5$（向下取整）并触发卡面【暴击】词条。
* **双色【暴击】牌**：同时投掷对应的 $2$ 颗属性骰，**取其中较高的一颗点数**与敌方暴击抵抗比对。
  * **超暴击（双色专属）**：若投出的 $2$ 颗骰子**同时达到敌方暴击抵抗**（或两颗骰子点数相同且 $\ge 4$），则触发**超暴击**，本次伤害直接 $\times 2$（或触发卡面【超暴击】强力效果）！

| 敌人级别 | 意图可见度 | 默认暴击抵抗线 |
| ----- | ----- | ----- |
| **普通小怪** | 意图完全公开 | $4$ |
| **精英敌人** | 意图半公开（显示类型，隐藏具体数值或目标） | $6$ |
| **首领（Boss）** | 按阶段与机制公开 | $7\text{--}8$ |

### 7.4 九大伤害属性与破弱点

所有造成伤害的卡牌均带有《最终物语》的九大伤害属性标识：**物理、风、雷、暗、地、火、冰、光、毒**。

* **易损（弱点）**：攻击命中敌人易损属性时，最终伤害 $\times 2$；
* **抗性**：攻击命中敌人抗性属性时，最终伤害 $\div 2$（向下取整）；
* **免疫 / 吸收**：按原规则将伤害降为 $0$ 或转为治疗。

## 8. 标准战斗轮次流程

每场战斗按「轮（Round）」推进，每轮严格按以下 $5$ 个阶段依序执行：

```
① 轮始与意图阶段
   ├─ 清空上一轮残留的自动物理/魔法护盾，重新获得本轮自动双盾（敏捷 ÷ 2 / 洞察 ÷ 2）
   ├─ 敌人揭示本轮行动意图与目标指向
   └─ 结算「退出升变」或宣告发动「进入升变」

② 补牌阶段
   ├─ 常态角色：第 1 轮抽 5 张，第 2 轮起每轮抽 3 张
   └─ 升变角色：从 10 张形态额外卡组中抽 5 张

③ 玩家阶段（全队自由穿插行动）
   ├─ 每名角色获得 3 AP，玩家之间可按任意顺序自由交替出牌与配合
   ├─ 可执行动作：打出卡牌、消耗 1 AP 前后排移动、执行 1 次 0 AP 贴充能动作、消耗充能转 MP/AP
   └─ 全员宣布行动完毕后，进入敌人阶段

④ 敌人阶段
   ├─ 按敌人意图自上而下依次结算攻击与技能（单体默认优先前排，前排空虚则打后排上轮最高输出）
   └─ 玩家可在此时机打出「时机牌」，为自己或相邻队友进行格挡与援护

⑤ 轮末结算阶段
   ├─ 场景命刻（如有）+1，结算回合末持续伤害或恢复
   └─ 清理本轮临时状态，手牌超过 7 张的玩家弃置多余手牌，进入下一轮
```
